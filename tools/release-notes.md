## 这一版做了什么

### 仪表盘：图表能指、能点、会动

- **悬停高亮**：鼠标移到柱子或折线上，那一根变亮、其余压暗，右上角浮出这格明细（是几月几号、哪个平台、多少条），光标变手型。趋势图悬停还给整列铺一条淡色竖带。
- **点击下钻**：趋势图点某一天 → 投递明细只看那天；平台对比点某一行 → 只看那个平台；城市环形点某一块 → 只看那个城市。跳过去后标题下留一个 `日期 11-18 ✕` 的标签，点 ✕ 撤掉；从仪表盘钻过去会先清掉上一次的筛选，避免被夹成 0 条。
- **入场动画约 220 ms**：柱子和折线按 Timer 插值从底部长出来，切页面时不再"啪"地出现。纯 GDI+，体积 +2 KB，没有引入任何第三方库，单 exe 依然成立。

### 修掉的 6 个问题

1. **「打开报告」读到旧文件**：`make-report.js` 不认数据目录，数据搬到 `data\` 后还往 `scripts\` 写。现在读写都走数据目录。
2. **"下次运行"跨天说错**：过了当天的点仍写"今天到点自动开始"。现在写 `明天 09:30` 或 `今天 14:00 自动开始`，KPI 数字过长自动换小一号字。
3. **平台对比的亮段是假的**：原来按 `回复率 × 3.2` 凑宽度，和"亮段 = 有回复"对不上。改为真实比例，右侧直接写 `回复 8 · 1.0%`。
4. **重启会把同一场再跑一遍**：启动时读 `runs.jsonl`，今天已跑过的时段不再触发（以前 10:00 重启会让上午场从 09:30 重投一轮）。
5. **招呼语时间线多出同一条**：对已是当前的版本再点「设为当前」会追加一条，把之前那段投递变成"无归属"。现在不追加；删掉正在用的版本会补一条回落记录；载入时把连续重复的版本并成最早那条。
6. **凌晨打开「数据自检」永远是红的**：第一个时段还没收工、今天还没跑过，却拿"今天 0 条"报不通过。现在这项写"还没到第一个投递时段的收工时间，先不算这一项"。

## 下载

`AutoApply-1.8.5-win-x64.zip`（约 27 MB）：解压到任意目录，双击 `AutoApply.exe` 即用。单文件、免安装、不用另装 .NET 或 Node。

数据在 exe 同目录的 `data\`（便携模式由 `AutoApply.data` 标记文件决定；没有标记则用 `%LOCALAPPDATA%\AutoApply`），升级覆盖 `scripts\` 不会再动到已有投递记录。

## 升级注意

- 覆盖前先关掉正在跑的程序（托盘右键退出）。
- 招呼语：v1.8.3 起只保留"当前在用"和你自己新建的版本；1.8.2 内置的 B/C 已被清掉。
