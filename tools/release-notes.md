## 这一版做了什么

一句话：**修掉"切页面卡死"的真凶，顺手把窗口修出圆角。**

### 卡顿：平台健康页每次重绘都在同步问 Chrome

`HealthPage.OnPaint` 里直接调 `ChromeAlive()` / `Tabs()` / `ChromeVersion()`，每重绘一次就发三个 HTTP 请求到 `127.0.0.1:9333`。Chrome 没开时 WebClient 还会走系统代理探测、一直等超时。

用 `--perf` 量每页"画一次"要多久：

| 页面 | 修前 | 修后 |
|---|---|---|
| 平台健康 | **4089 ms** | 19 ms |
| 运行分析 | 25 ms | 18 ms |
| 仪表盘 | 26 ms | 29 ms |

鼠标一动就要重绘，重绘一次卡 4 秒——所以"运行分析 ↔ 平台健康 来回切"整窗发僵。现在：绘制只读缓存、后台每 4 秒刷一次；本机请求用禁用代理 + 1.2 秒超时的客户端；浏览器没连上时不再四站挨个等超时，一次判定。

### 悬停动画只重画那一块

以前悬停插值每次整页重绘（20 ms × 60 次/秒）。现在只脏按钮自己那块矩形，找不到矩形才退回整页。

### 窗口圆角

纯 WS_POPUP（`FormBorderStyle.None`）下 `DWMWA_WINDOW_CORNER_PREFERENCE` 不生效，实测仍是直角。改成保留 `WS_THICKFRAME` + `WM_NCCALCSIZE` 清零非客户区，DWM 才会给圆角与投影；Win11 那条 1px 浅色边框染成窗口底色。

### 平台健康页的字

「未连接 / 已连接 / Chrome 版本」这类状态词从 31pt 数字字体改成 19pt，和旁边数字卡同一层级；副标题超宽截断加省略号；文案给出下一步（点「全部检查」或先把浏览器打开）。

### 顺带

- `--render` 改为抓窗口客户区（保留系统边框后 `DrawToBitmap` 会把标题栏画进截图）。

## 下载

`AutoApply-1.8.6-win-x64.zip`：解压到任意目录，双击 `AutoApply.exe` 即用。单文件、免安装、不用另装 .NET 或 Node。

数据在 exe 同目录的 `data\`（便携模式由 `AutoApply.data` 标记文件决定；没有标记则用 `%LOCALAPPDATA%\AutoApply`），升级覆盖程序文件不会动到已有投递记录。

## 升级注意

- 覆盖前先关掉正在跑的程序（托盘右键退出）。
- 安装包不附带 `config.json`：城市、关键词、招呼语只在你自己的数据目录里；首次运行按向导生成。
- 这一版没有数据结构变化，1.8.5 → 1.8.6 直接覆盖 exe 即可。
