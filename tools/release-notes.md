## 这一版加了什么

### 1. 投递明细：搜索框 + 城市快捷筛选 + 清空筛选

页面顶部从一层工具栏拆成两层，找某一条记录不用再翻几十页：

- **搜索框**：公司、岗位、城市、关键词、薪资都能搜；用空格（或中文逗号）隔开多个词 = 同时包含。`Ctrl+F` 直接把光标放进搜索框，右侧 `✕` 清空。
- **城市快捷筛选**：按当前筛选结果里的城市实时生成（出现最多的排前面，如 北京 / 杭州 / 上海 / 广州 / 深圳 / 西安 / 成都 / 重庆），点一下只看这个城市，再点「全部城市」撤销；它和搜索、时间范围、平台**叠加生效**。
- **清空筛选**：一次把搜索、城市、时间范围、平台全部重置（时间回到「全部」）。
- 空结果时给的是可操作提示：搜索框里打了东西就提示「少打几个字」或点「清空筛选」，否则提示换时间范围或平台。

实测：2203 条 → 搜「实施」2118 条 → 再点「上海」287 条，副标题旁的「城市 上海 ✕」可单独撤销这一个条件。

### 2. 运行日志：右侧有真正的滚动条

- 右侧新增 6px 轨道，滑块高度按「可见行数 / 总行数」算；**拖滑块、点轨道空白处跳转**都可以，副标题也改成了「鼠标滚轮 / 拖动右侧滚动条翻看历史」。
- 滚动位置改成按**起始行号**记录。旧代码注释写着 `0 = 最底部`，实际却按「0 = 最顶部」在用——这是老 bug，这版一并纠正：**你正往上翻看历史时，新来的日志不会把视图拉回底部**；只有本来就贴着底部时才会自动跟随。
- 超长行在滚动条左边被裁切，不再压住滑块。

### 3. 顺带修的

- 在搜索框里按 `Esc` 不再顺手触发全局「停止投递」。
- 版本号 1.9.0（「关于」页可见）。

## 升级方式

1. 托盘图标右键 → 退出（或任务管理器结束 AutoApply）；
2. 解压覆盖 `AutoApply.exe`（`config.json` 是你的数据，包里不带，不会被覆盖）；
3. 重新打开即可，无需重登。

## 已知的使用前提（未变）

程序自己是 low 完整性级别、拉不起 Chrome，浏览器由 `启动` 文件夹里的启动项在登录 Windows 时拉起，程序只负责连 9333 端口。若平台健康页说浏览器没连上，先双击程序目录的 `启动调试浏览器.cmd`，或在平台健康页点「重开」。
