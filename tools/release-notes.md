## 这一版加了什么

### 1. 登录态搬进数据目录，并且只授当前账户

- 受控 Chrome 的登录态从「exe 旁边」挪到**数据目录**下的 `browser-profile\`：便携版就是 `data\browser-profile`（跟程序同一个盘，同盘只做目录改名，**不多占 C 盘空间**，也不用重新登录）；非便携版则放 `%LOCALAPPDATA%\AutoApply`。
- 旧版本留在程序目录的那份会在首次启动时自动搬过去，校验新位置的 Cookies 后才删旧目录；搬失败就继续用旧位置，不会把你搞成「要重新登录」。
- 目录权限收紧为**只有当前 Windows 账户**（SYSTEM / 管理员保留），同机其他账户读不到这四个平台的登录态。
- 「打开浏览器」和相关说明文字同步改为「登录状态保存在数据目录的 browser-profile」。

### 2. 投递前核对 9333 端口是谁的

- 每一轮开跑前先问系统「谁在监听 9333」，再看那个进程用的登录态目录是不是本程序那份。
- 不是本程序的浏览器 → **直接停下并说明原因**，避免脚本把「投递」点进你日常浏览器的窗口、或另一个旧副本的窗口里。
- 系统权限不足、读不到进程命令行时只记日志放行，不阻塞正常使用。

### 3. 安装包可核对（SHA256）

- zip 里带 `SHA256SUMS.txt`（`AutoApply.exe` 的哈希），下载页同时提供 `AutoApply-<版本>-win-x64.zip` 的哈希，Release 说明里附核对命令：

```cmd
certutil -hashfile AutoApply-1.10.0-win-x64.zip SHA256
```

- `README.md` 新增「安全说明」：对外只连四个招聘网站 + `127.0.0.1:9333`，程序里没有平台密码，自动更新只读版本号不下载执行。

### 4. 城市与筛选（延续上一轮）

- 「平台与关键词 → 目标城市」是搜索范围，「匹配规则 → 城市」是投递范围的子集：不选 = 全投，选了谁只投谁。
- 城市/词表卡片的「×」靠右独立成一块，点文字不会再误删；按钮宽度未变。

### 5. 平台健康：登录态判断修好

- 数据目录与代码目录分开以后，体检探针还在数据目录（`data\`）里找 `evalfile.js`，便携版里根本没有这个文件，于是每一站都判成「无法判断 / 页面没响应」。现在探针固定从 `scripts\` 取脚本，真窗口复测：BOSS、智联、前程都显示「已登录」。
- 探针真的失败时也不再只说「页面没响应」，会按原因给一句能照做的提示：标签页卡住 → 点「重开」；程序不完整（缺 scripts）→ 直说缺哪个文件；node 起不来 → 说 node。

### 6. 顺带

- 版本号 1.10.0（「关于」页可见）。
- 旧版本目录/安装包已清理，只保留 1.10.0 一份，避免误开旧副本抢单实例。

### 7. 手机看板（同一个 Wi-Fi）

- 新增局域网网页：手机连同一个 Wi-Fi，用浏览器打开「平台健康」页底部那张卡上的地址（形如 `http://192.168.8.136:8737`），输入同一行的 6 位口令，就能看四站标签页 / 登录态 / 验证码 / 今天投递数 / 最近一轮结果，还能看最近几行日志、点「全部重开 / 开始一轮 / 停止」。
- 不装 App、不用云服务、不用远程桌面：程序自己开一个极简网页服务，普通权限即可（不需要管理员加 urlacl）。手机页每 5 秒自动刷新。
- 边界：只接受 `10.x / 172.16–31.x / 192.168.x / 本机回环`，其它来源直接 403；明文 HTTP，只给家里/办公室局域网用，**不要映射到公网**；口令连错 5 次锁 10 分钟，健康页「换口令」可立即作废旧登录。
- 第一次用需要管理员右键 `tools\允许手机访问.cmd` 放行 TCP 8737（只放行本网段）。不想用时把 `config.json` 的 `"WebEnabled"` 改成 `false`。

### 8. 界面：GitHub 皮肤、新的切换面板、右上角胶囊

- 夜间皮肤新增一套 **GitHub**，取值和 github.com 深色一致：画布 `#0D1117`、卡片 `#161B22`、边框 `#30363D`、文字 `#E6EDF3`、主按钮 `#238636`、成功绿 `#3FB950`；日间切到 GitHub 时用 github.com 浅色（白底、`#D0D7DE` 边、`#1F883D` 按钮）。
- 右上角原来只有一颗小月亮加一个贴着边角的小三角，现在是一整颗可点的胶囊：「月亮/太阳 + 当前皮肤名 + 细箭头」，悬停提亮，点开就是新面板。
- 新面板一行一套皮肤：左边用这套皮肤自己的画布/面层/强调色画缩略图，中间名字和一句说明，右边选中绿勾；点一下立即换肤，底部一行「切换到夜间/日间模式」。点面板外或按 `Esc` 收起。
- 皮肤选择记在 `config.json`，下次启动保持。

### 9. 修掉两处界面错位

- 右上角胶囊原来整块 200×44 都是透明控件，页面上的按钮只要落进这块矩形，上半截就会被抹成底色、点击也不响应（运行日志「打开报告」、招呼语「新建一版」、仪表盘「待命中」都中过招）。现在透明区域裁成胶囊、最小化、关闭三个圆角形状，页面的右上操作也统一落在胶囊下方。
- 「匹配规则」城市胶囊悬停后留下半截绿环、或高亮卡住不消失：局部重画时只画了半颗胶囊，而且命中区会被整页清空。现在悬停进出都重画整颗，局部重画不再清命中区，词和「×」两块点击区都指向整颗。

## 升级方式

1. 托盘图标右键 → 退出（或任务管理器结束 AutoApply）；
2. 解压覆盖 `AutoApply.exe`（`config.json`、`data\` 是你的数据，包里不带，不会被覆盖）；
3. 重新打开即可：首次启动会把旧登录态自动搬进 `data\browser-profile`，四个平台不用重新登录。

## 已知的使用前提（未变）

- 程序需要以**普通（medium）权限**运行：exe 所在文件夹若被系统/安全软件打了「低完整性」标签，Chrome 会被拒绝启动。带标签时右键 `tools\fix-integrity-label.cmd` 以管理员身份运行一次即可。
- 专用浏览器由程序自己拉起（登录态在 `data\browser-profile`），日常的 Chrome 不受影响；也可以双击 `启动调试浏览器.cmd` 手动开。
